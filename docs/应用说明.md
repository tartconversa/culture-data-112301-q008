# 估价应用说明

基于 data/ 合成经营资料的 Python 估价应用，覆盖四个环节：接收项目、估价、
确认报价、追踪变更。代码在 estimation/，演示入口 tools/estimate.py，
测试在 tests/。

```sh
python3 tools/estimate.py            # 端到端演示（写 state/ 与 outputs/）
python3 -m unittest discover -s tests -v
```

## 接收项目

`estimation.schema.load_dataset` 按 data/catalog.json 校验内容指纹、字段类型
与直接外键，失败即拒绝读取。`EstimationApp.breakdowns()` 给出经营分解：各客户
审稿工时与未确认意见占比、各复杂度返工（质量）工时占比、共享素材的跨项目复用、
项目状态分布。open 与 cancelled 项目的已发生工时只作为下界，不当完结项目解释。

## 估价

`estimation.model`：

- 工时按 (任务类型, 原因) 分层为经验池；concept 的 initial 池与 derivative 的
  quality/review/scope 池分开。报价模拟时概念设计只抽一次，衍生件逐件先抽原因
  再抽工时——父任务工时绝不复制到衍生件。
- scope（客户新增范围）工时不进固定总价基础成本，单列“可计费范围”分布。
- 删失校正：只有 accepted 项目视为最终成本已知；open/cancelled 一律右删失，
  用 Kaplan-Meier 在项目团队承担工时上估计校正因子（当前资料约 1.10），
  同时报告未校正均值，避免只反映已结项的便宜项目。取消风险区分客户原因与
  承包方原因分别报告。
- 回测 `backtest()` 按当时信息重放：目标项目只用其签约日之前签约、且签约日
  之前可观察到的工时拟合；该日前未验收的项目一律删失；特征限签约时白名单
  （客户、范围构成、约定轮数、地域、素材、交期），后来发生的反馈与变更单
  不作签约前特征。输出各分位覆盖率与平均偏差，供判断报价档位是否保守。

## 组合报价

`estimation.pricing.build_quote`：

- 可行性：素材地域覆盖、授权期限覆盖交期、独占冲突；创作者技能/地域/窗口产能
  （扣减已被其他订单承诺的工时）；外包条款（OS1 整包不可拆，OS2 分阶段最低
  8 小时）。任一阻断性问题未过，报价标记不可行且不能被接受。
- 成本分布：授权费 + 外包包价（预付沉没）+ 内部工时（按成本率从低到高分配），
  内部不足时按边际外包价增购并给出超支概率。
- 价格阶梯 P50/P80/P95（默认毛利 30%），推荐 P80；每份报价写明置信说明与
  除外条款，不用预测均值冒充固定总价保证。
- 共享对照：组合报价 vs 拆成单件报价相加（重复计入共享概念设计与授权）vs
  逐项最低价（可能漏掉共同前置条件），量化重复计成本金额。
- `compare_scenarios` 比较约定轮数、客户响应期限与替代素材条款，每个情景说明
  风险、成本与可承诺范围的变化。
- 每份报价的依据（模型版本、输入、工时分布、资源方案、假设）完整存入
  state/quotes/，供接受后与履约中核对。

## 确认报价

`estimation.orders.OrderBook.accept`：

- 报价过有效期不能接受；接受时重新确认素材权利仍然有效、创作者时段仍然够用。
- 互斥：同一独占素材不能被不同客户的订单同时消耗；同一整包资源（OS1）不能被
  两份订单同时锁定；分阶段包（OS2）累计承诺不得超过本包工时。
- 接受后范围与价格冻结，当时依据随订单保存；预测模型更新不会缩小已接受订单的
  范围。外包确认列为尚欠成立条件：客户已同意不等于全部可交付，订单状态呈现
  尚欠条件（如“OS2 尚欠 8.0 小时确认”），整包资源的部分确认不构成立条件。

## 追踪变更与履约

- 变更提案未接受前不改变原订单；接受后以变更单追加（价格、范围、交期），
  原依据保留。
- 履约意见按合同与人工确认归责：约定轮次内审稿→团队承担；超轮次→另行计费；
  已确认质量缺陷→团队承担；已确认新增范围→客户变更单；未确认→不归责。
  客户响应超期只有合同约定且事实确认后才影响责任，应用不擅自归责。
- 实际工时进入时 scope 与质量严格分列；毛利报告核对实际成本与接受时预期成本
  的偏差。`learn_from_order` 把已确认经验回流到对应工时池（质量进质量池、
  范围进范围池），范围变化造成的成本不会喂回成质量返工。

## 已知简化

- 删失校正因子是项目级全局因子，未按客户或复杂度分层（当前资料每格样本不足）。
- 创作者周产能假设在交期窗口内每周相同；资料只给出一周的产能登记。
- 衍生件工时原因按经验占比独立抽取，未建模项目内相关性。
- 回测显示当前模型偏保守（P80 覆盖率高于 80%），报价档位选择应参考回测结果。
