# 跨境设计服务的返工风险与组合报价资料约定

以下记录全部为本地合成数据，业务名称、参与方及数量不对应真实企业。

日期使用公历，带Z的时间为UTC。缺失值使用JSON null，空列表表示已知集合为空。资料主键仅表示该来源记录身份，业务版本与原始对象字段另行保留。

工时单位为小时，货币为USD美分。历史观测截止2026-09-30，未终止项目只观察到此日。子任务的parent表示共享前置设计，不表示应把父任务工时复制到每个子任务。
quality为人工确认的质量缺陷，scope为新增范围，review为原约定轮次审稿，未确认意见不产生自动归责。
合同约定客户已接受前的变更提案不改变原范围。已确认质量缺陷由团队承担，客户响应超期只有合同明确约定且事实确认后才影响责任。
OS1整包时段不可拆购，OS2允许8小时以上分阶段采购。外部回执的实际确认工时决定可依赖的资源。

## projects

历史报价与真实结项状态。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| id | str | 项目 |
| customer | str | 客户 |
| signed_on | str | 签约日 |
| deadline | str | 交期 |
| closed_on | str / null | 实际终止或验收日，空为仍在履约 |
| state | str | 履约状态及取消责任 |
| quoted_minor | int | 报价美分 |
| rounds_included | int | 包内修订轮数 |
